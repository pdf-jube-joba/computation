# 多テープチューリングマシン

正の整数 `k` 本の左右無限テープと、それぞれ独立したヘッドを持つ決定的チューリングマシン。
1回の遷移では、全テープのヘッドにある記号を読み、その組と状態から遷移を選ぶ。
全ヘッド位置への書き込みを行い、それぞれのヘッドを `\L`（左）、`\R`（右）、`\C`（その場）に動かす。
受理状態に入るか、現在の状態・読み取り記号の組に対応する遷移がなければ停止する。
停止時の出力は全テープであり、受理・不受理の区別は状態の受理状態集合への所属で表す。

## コードの形式

先頭の4行にテープ数、有限アルファベット、初期状態、受理状態を指定する。
空白記号は `-` で、アルファベットに必ず含める。ほかの記号と状態名は識別子。
受理状態はカンマで区切り、空集合の場合は4行目を空行にする。

その後は `読み取り記号列,現在状態,書き込み記号列,次状態,方向列` の5列。
記号列と方向列は空白区切りで、テープ数と同じ長さにする。
`#` から行末までをコメントとして扱う。遷移表の空行は無視する。

```text
tapes: 2
alphabet: -,a,b
copy
done
a -,copy,a a,copy,\R \R
b -,copy,b b,copy,\R \R
- -,copy,- -,done,\C \C
```

この機械は第1テープの `a`・`b` を第2テープにコピーする。
遷移の重複、受理状態からの遷移、アルファベット外の記号はエラーになる。

## 入出力

1行に1本ずつ、1テープ版と同じ `左側|ヘッド|右側` の形式で指定する。
テープ本数はコードの指定と一致させ、全セルを指定したアルファベットの記号にする。

```text
|a|b,a
|-|
```

上のコードを実行すると、出力は次のようになる。

```text
a,b,a|-|
a,b,a|-|
```

実行時の追加入力・途中出力は空文字列。保存状態にはコード、現在状態、全テープを含み、
描画では遷移表と各テープのヘッド位置を表示する。
