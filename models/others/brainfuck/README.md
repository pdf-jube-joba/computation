# Brainfuck

8 命令でテープとバイト列を操作するモデル。基本命令は
[Urban Müller の配布物に含まれる README](https://gist.github.com/rdebath/0ca09ec0fdcf3f82478f#file-readme)
に対応する。

| 命令 | 動作 |
| --- | --- |
| `>` / `<` | ヘッドを右 / 左に一セル動かす |
| `+` / `-` | 現在のセルを 1 増やす / 減らす |
| `.` | 現在のセルを一バイト出力する |
| `,` | 次の入力バイトを現在のセルに書く |
| `[` | 現在のセルが 0 なら、対応する `]` の直後へ進む |
| `]` | 現在のセルが 0 でなければ、対応する `[` の直後へ戻る |

この実装では、セルは `0..255` で巡回し、テープは右へ必要に応じて伸びる。
初期状態は全セル 0、ヘッドは左端。左端からの `<` はエラー。
入力が尽きた後の `,` は 0 を書く。
8 命令以外の文字は無視するが、コメント中に書いた命令文字も実行対象になる。
空プログラム・空ループは許可し、対応しない括弧は構文エラーにする。

## 入出力と実行

モデル名は `brainfuck`。Code は Brainfuck のプログラム。
AInput は `[72, 105]` のようなバイト値のリストで、空文字列は `[]` と同じ。
文字コードに依存せず、0 や 255 も入出力できるように数値で指定する。
RInput は空文字列。`.` の step の ROutput に出力したバイト値を返し、
ほかの命令では空文字列を返す。FOutput は、それまでに出力したバイト列全体。
例えば `[72, 105]` は ASCII の `Hi` に対応する。

入力が尽きるまで読み書きする例：

<div data-model="brainfuck">
<template data-default-code>
,[.,]
</template>
<template data-default-ainput>
[72, 105]
</template>
</div>

結果は `[72, 105]`。入力に含まれる 0 でもループは終了する。

```sh
opam exec -- dune exec repl-machine -- model brainfuck --code ',[.,]' --ainput '[72, 105]'
```

空行を入力するたびに一命令進む。描画では命令位置、テープ、残りの入力、蓄積した出力を確認できる。
最後の `.` も実行時出力を返し、その次の step で停止する。
