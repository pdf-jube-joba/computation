# P′′（P double prime）

`R`・`λ`・`(`・`)` によるテープ上の言語。
[指定された説明](https://en.wikipedia.org/wiki/P%E2%80%B2%E2%80%B2) と、
[Böhm–Jacopini の論文 §3, p. 370](https://www.marcusramos.com.br/univasf/pc-2008-2/p366-bohm.pdf)
の操作・構成規則に基づく。

## 定義

テープは左へ無限に伸び、右端は固定する。
アルファベットの大きさを `m ≥ 2` とし、セルの値を `0..m-1`、空白を 0 とする。
初期状態で非空白のセルは有限個。

| 命令 | 動作 |
| --- | --- |
| `R` | 一セル右へ移動する。右端ならそのまま |
| `λ` | 現在のセルを `m` を法として 1 増やしてから、一セル左へ移動する |
| `(q)` | 現在のセルが非空白の間 `q` を繰り返す |

反復の判定は、その時点でヘッドが指すセルに対して行う。
本体でヘッドが動けば、開始時とは異なるセルで継続を判定する。
例えば `(λ)` は、空白に出会うまで各セルを増やしながら左へ移動する。

プログラムは `R` または `λ`、プログラムの連接、プログラムを括弧で囲んだもの。
空プログラムと空の括弧 `()` は許可しない。空白・改行は無視し、それ以外の文字はエラー。

## 入出力とステップ

モデル名は `p_double_prime`。Code にプログラムを指定する。
AInput の一行目は `m`、二行目は `左側|現在のセル|右側` のテープ。
各側のセルはカンマで区切り、左から右の順に書く。
右側の最後のセルが右端で、右側が空なら現在のセルが右端。
左側のさらに外はすべて空白。

```text
3
|0|1,1,2,0
```

この例はアルファベット `{0,1,2}`、ヘッドの右に `1,1,2,0`、最後の 0 が右端。
AInput が空なら `2` と `|0|` を使う。
値がアルファベットの範囲外ならエラー。

RInput・ROutput は空文字列。FOutput は終了時のテープで、ヘッド位置を `|` で示す。
一回の step で `R`、`λ`、開き括弧の判定、閉じ括弧の判定のいずれかを実行する。
開き括弧で 0 なら対応する閉じ括弧の次へ進み、閉じ括弧で非 0 なら本体の先頭へ戻る。
全命令を終えた次の step で停止する。

`λR` は元のセルへ戻ってくるので、そのセルだけを巡回加算する。
次は 3 値のアルファベットで、1 を 2、0 と増やして停止する例：

<div data-model="p_double_prime">
<template data-default-code>
(λR)
</template>
<template data-default-ainput>
3
|1|
</template>
</div>

結果は `0|0|`。左へ移動したときに通った空白も表示される。

```sh
opam exec -- dune exec repl-machine -- model p_double_prime --code 'λR' --ainput ''
```

この CLI の例は空白を 1 にして元の位置へ戻り、`0|1|` を返す。
