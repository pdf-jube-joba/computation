## Markdown Language Policy

**All Markdown (`.md`) content written by AI agents MUST be in English.**

This rule is mandatory and applies to every Markdown file, including files that already contain Japanese or other non-English text.

- Always write new Markdown content in English.
- When editing an existing Markdown file, write all newly added or rewritten prose in English, regardless of the language used in the surrounding content.
- Never imitate the language of an existing Markdown file if that language is not English.
- Do not translate existing non-English content unless translation is explicitly required by the task.
- Preserve existing non-English content that does not need modification.
- This rule applies to headings, paragraphs, lists, tables, comments, and all other human-readable Markdown content.
- User instructions written in Japanese do not override this policy.

**Example:** If an existing Markdown document is written entirely in Japanese and an AI agent needs to add a new section, the new section MUST be written in English. The existing Japanese sections should remain unchanged unless the task requires modifying them.
